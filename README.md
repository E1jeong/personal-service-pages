# Personal Service Pages

Static public pages for small personal tools. Each tool owns its homepage and privacy policy under its own directory. No credentials or private data belong here.

Publish this repository as a GitHub Pages project site from the `main` branch root. The public Calendar URLs will be:

- `https://e1jeong.github.io/personal-service-pages/calendar-reminder/`
- `https://e1jeong.github.io/personal-service-pages/calendar-reminder/privacy.html`

A Google Search Console HTML verification file can be placed at the repository root when issued.
